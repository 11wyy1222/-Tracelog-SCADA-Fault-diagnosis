## 1. preprocess_3D.py — 数据预处理脚本

### 1.1 功能概述

将原始 CSV Tracelog 数据转换为 PyTorch 张量格式（`.pt`），完成特征提取、数据划分和标准化，生成可直接用于模型训练的 `train.pt`、`val.pt`、`test.pt` 文件。

### 1.2 命令行接口

```bash
python preprocess_3D.py --config <配置文件路径> [--override key1=value1 key2=value2 ...]
```

### 1.3 参数说明

| 参数 | 类型 | 必需 | 默认值 | 说明 |
|------|------|------|--------|------|
| `--config` | str | ✅ | — | 预处理配置文件路径（YAML格式） |
| `--override` | str[] | ❌ | — | 覆盖配置参数，格式 `key=value`，支持嵌套键如 `split.test_size=0.3` |

### 1.4 配置文件对照（configs/preprocess.yaml）

```yaml
paths:
  label_file: "标签文件路径(.csv)"        # 包含样本路径和标签的索引文件
  config_file: "传感器配置表路径(.csv)"    # tracelog标签点配置表
  output_dir: "输出目录"                  # 生成的.pt文件保存位置

features:
  target_tags:                            # 需要提取的传感器通道列表
    - grRotorSpeedFormSpeedRelay1
    - grRotorSpeedFormSpeedRelay2
    - grRotorSpeedFromCounterModule1
    - rotor_speed

processing:
  max_seq_len: 12000                      # 统一时间步长度
  missing_value_method: "interpolate"     # 空值处理: interpolate/ffill/bfill/mean/zero
  padding_mode: "constant"                # 填充模式: constant/edge/reflect

normalization:
  method: "zscore"                        # 标准化: zscore/minmax/robust/none
  save_stats: true                        # 是否保存标准化统计量
  stats_filename: "normalization_stats.npz"

split:
  test_size: 0.4                          # 测试+验证集占比
  val_test_split: 0.5                     # 验证集在(测试+验证)中的占比
  random_state: 42                        # 随机种子
  stratify: true                          # 是否分层抽样

output:
  train_file: "train.pt"
  val_file: "val.pt"
  test_file: "test.pt"
```

### 1.5 执行流程

```
加载配置 → DataPreprocessor.process() → split_and_normalize() → save_datasets()
```

1. 读取 YAML 配置，应用 `--override` 覆盖
2. `DataPreprocessor(config)` 初始化预处理器
3. `process()` — 读取原始 CSV，提取特征，返回 `(X, y)`
4. `split_and_normalize(X, y)` — 按配置比例划分数据集并标准化
5. `save_datasets(data_splits)` — 保存为 `.pt` 文件

### 1.6 输出文件格式

每个 `.pt` 文件包含：
```python
{
    'samples': Tensor[N, C, L],  # N=样本数, C=通道数, L=时间步
    'labels':  Tensor[N]         # 整数标签
}
```

### 1.7 使用示例

```bash
# 基本用法
python preprocess_3D.py --config configs/preprocess.yaml

# 覆盖参数
python preprocess_3D.py --config configs/preprocess.yaml \
    --override split.test_size=0.3 normalization.method=minmax

# 修改输出目录
python preprocess_3D.py --config configs/preprocess.yaml \
    --override paths.output_dir=./data/my_dataset
```

## 2. train.py — 统一训练脚本

### 2.1 功能概述

统一的模型训练入口，支持深度学习模型（TSLANet、TS-TCC、base_CNN）、储层计算模型（RC）和传统机器学习模型（RandomForest、SVM、XGBoost、LightGBM、KNN、LogisticRegression）。通过配置文件切换模型，命令行参数可覆盖配置。

### 2.2 命令行接口

```bash
python train.py --config <配置文件路径> [可选参数]
```

### 2.3 参数说明

| 参数 | 类型 | 必需 | 默认值 | 说明 |
|------|------|------|--------|------|
| `--config` | str | ❌ | `config.yaml` | YAML 配置文件路径 |
| `--model` | str | ❌ | 配置文件值 | 模型名称，覆盖 `experiment.model` |
| `--dataset` | str | ❌ | 配置文件值 | 数据集名称，覆盖 `dataset.selected` |
| `--training_mode` | str | ❌ | 配置文件值 | 训练模式，覆盖 `training.mode` |
| `--device` | str | ❌ | 配置文件值 | 运行设备 `cuda`/`cpu`，覆盖 `device` |
| `--seed` | int | ❌ | 配置文件值 | 随机种子，覆盖 `experiment.seed` |
| `--batch_size` | int | ❌ | 配置文件值 | 批次大小，覆盖 `training.batch_size` |
| `--num_epochs` | int | ❌ | 配置文件值 | 训练轮数，覆盖 `training.num_epochs` |

> 参数优先级：命令行 > 配置文件 > 内置默认值

### 2.4 支持的模型与训练器映射

| 模型名称 | 类别 | 训练器 | 输入维度 | 设备 |
|----------|------|--------|----------|------|
| TSLANet | 深度学习 | UnifiedTrainer | 3D `[N,C,L]` | GPU/CPU |
| TS-TCC | 深度学习 | UnifiedTrainer | 3D `[N,C,L]` | GPU/CPU |
| base_CNN | 深度学习 | UnifiedTrainer | 3D `[N,C,L]` | GPU/CPU |
| RC | 储层计算 | RCTrainer | 3D `[N,C,L]` | GPU/CPU |
| RandomForest | 传统ML | MLTrainer | 2D `[N,F]`（自动展平） | CPU |
| SVM | 传统ML | MLTrainer | 2D `[N,F]` | CPU |
| XGBoost | 传统ML | MLTrainer | 2D `[N,F]` | CPU |
| LightGBM | 传统ML | MLTrainer | 2D `[N,F]` | CPU |
| KNN | 传统ML | MLTrainer | 2D `[N,F]` | CPU |
| LogisticRegression | 传统ML | MLTrainer | 2D `[N,F]` | CPU |

### 2.5 训练模式

| 模式 | 配置值 | 说明 |
|------|--------|------|
| 监督学习 | `supervised` | 标准有标签训练 |
| 自监督预训练 | `self_supervised` | 无标签对比学习预训练（TS-TCC/TSLANet） |
| 微调 | `fine_tune` | 加载预训练权重后全参数微调 |
| 线性评估 | `train_linear` | 冻结主干网络，仅训练分类头 |
| 随机初始化 | `random_init` | 随机初始化后冻结部分层训练 |

### 2.6 配置文件对照（configs/config.yaml）

```yaml
experiment:
  description: 'Exp1'          # 实验名称 → 日志子目录
  run_description: 'run1'      # 运行名称 → 日志子目录
  seed: 123                    # 随机种子
  model: 'TSLANet'             # 模型选择

training:
  mode: 'supervised'           # 训练模式
  num_epochs: 100              # 训练轮数
  batch_size: 16               # 批次大小
  learning_rate: 0.001         # 学习率
  weight_decay: 0.0003         # 权重衰减
  beta1: 0.9                   # Adam β1
  beta2: 0.99                  # Adam β2

pretraining:
  load_pretrained: false       # 是否加载预训练
  pretrained_path: null        # 预训练模型路径
  delete_layers: ['logits']    # 加载时删除的层
  freeze_backbone: false       # 是否冻结主干

dataset:
  selected: 'chaosu'           # 数据集名称
  data_path: './data'          # 数据根目录

# 模型特定配置（按模型名称索引）
TSLANet:
  emb_dim: 128
  depth: 2
  patch_size: 8
  dropout_rate: 0.15
  ...

# 数据集特定配置（按数据集名称索引）
dataset_configs:
  chaosu:
    input_channels: 4
    seq_len: 12000
    num_classes: 4
    num_channels: 4
```

### 2.7 执行流程

```
加载配置 → 设置随机种子 → 加载数据 → 创建模型 → [加载预训练] → 创建优化器 → 选择训练器 → 训练 → 测试评估 → 保存
```

### 2.8 输出目录结构

```
experiments_logs/
└── {experiment.description}/
    └── {experiment.run_description}/
        └── {training_mode}_seed_{seed}/
            ├── logs_YYYYMMDD_HHMMSS.log       # 训练日志
            ├── config.yaml                     # 配置快照
            ├── metrics.csv                     # 训练指标（如有）
            ├── classification_report.xlsx      # 分类报告（监督模式）
            ├── confusion_matrix.png            # 混淆矩阵图（监督模式）
            └── saved_models/
                ├── ckp_best.pt                 # 最佳模型检查点
                └── ckp_last.pt                 # 最后一轮检查点
```

### 2.9 使用示例

```bash
# 基本训练（使用配置文件默认值）
python train.py --config configs/config.yaml

# 指定模型和训练模式
python train.py --config configs/config.yaml \
    --model TSLANet --training_mode supervised --num_epochs 50

# 自监督预训练
python train.py --config configs/config.yaml --training_mode self_supervised

# 微调（需先完成自监督预训练）
python train.py --config configs/config.yaml --training_mode fine_tune

# 传统ML模型训练
python train.py --config configs/config.yaml --model RandomForest

# 指定设备和批次大小
python train.py --config configs/config.yaml \
    --device cpu --batch_size 32 --seed 42
```

## 3. predict.py — 统一预测脚本

### 3.1 功能概述

统一的模型推理入口，支持所有已训练模型的预测。集成故障诊断映射功能，可输出故障原因和处理方案。支持内置数据集和外部数据文件两种输入方式。

### 3.2 命令行接口

```bash
python predict.py --checkpoint <检查点路径> --config <配置文件路径> [可选参数]
```

### 3.3 参数说明

| 参数 | 类型 | 必需 | 默认值 | 说明 |
|------|------|------|--------|------|
| `--checkpoint` | str | ✅ | — | 模型检查点路径（`.pt` 文件） |
| `--config` | str | ✅ | — | 配置文件路径（`.yaml` 文件） |
| `--model` | str | ❌ | 从checkpoint读取 | 模型名称（覆盖checkpoint中的记录） |
| `--mapping` | str | ❌ | `class_mapping.xlsx` | 故障诊断映射 Excel 文件路径 |
| `--no-diagnosis` | flag | ❌ | `false` | 禁用故障诊断功能 |
| `--data_file` | str | ❌ | — | 外部数据文件路径（`.pt`），与 `--dataset` 二选一 |
| `--dataset` | str | ❌ | `chaosu` | 数据集名称（使用内置数据集时） |
| `--data_path` | str | ❌ | `./data` | 数据根目录（使用内置数据集时） |
| `--mode` | str | ❌ | `test` | 预测数据集分片：`train`/`val`/`test` |
| `--device` | str | ❌ | `cuda` | 运行设备：`cuda`/`cpu` |
| `--output` | str | ❌ | 自动生成 | 输出 JSON 文件路径 |
| `--batch_size` | int | ❌ | `128` | 批处理大小 |
| `--show_samples` | int | ❌ | `5` | 控制台显示前 N 个样本的预测详情 |
| `--show_diagnosis` | flag | ❌ | `false` | 为每个样本显示详细故障诊断信息 |

### 3.4 数据输入方式

#### 方式一：内置数据集（默认）

从 `{data_path}/{dataset}/` 目录加载预处理好的 `.pt` 文件，通过 `--mode` 选择 train/val/test 分片。

```bash
python predict.py \
    --checkpoint experiments_logs/Exp1/run1/supervised_seed_123/saved_models/ckp_best.pt \
    --config configs/config.yaml \
    --dataset chaosu --mode test
```

#### 方式二：外部数据文件

加载任意 `.pt` 文件，文件格式要求：

```python
# 带标签（可计算准确率）
{'samples': Tensor[N, C, L], 'labels': Tensor[N]}

# 无标签（纯预测模式）
{'samples': Tensor[N, C, L]}
```

```bash
python predict.py \
    --checkpoint experiments_logs/.../ckp_best.pt \
    --config configs/config.yaml \
    --data_file external_data/new_samples.pt
```

### 3.5 模型预测策略

| 模型类别 | 预测方式 | 设备 | 数据处理 |
|----------|----------|------|----------|
| 深度学习（TSLANet, TS-TCC, base_CNN） | 迭代预测（逐批次） | GPU/CPU | 3D 输入 `[N,C,L]` |
| RC | 批量预测（一次性） | GPU/CPU | 3D 输入 `[N,C,L]` |
| 传统ML（RandomForest, SVM 等） | 批量预测（一次性） | CPU | 自动展平为 2D `[N,F]` |

### 3.6 输出结果

#### 控制台输出

- 模型和数据加载信息
- 预测进度
- 准确率统计（有标签时）
- 各类别准确率 / 预测分布
- 故障诊断汇总（启用时）
- 置信度统计（平均/最小/最大/标准差/分布）

#### JSON 输出文件

默认保存路径：`{checkpoint所在目录}/predictions_{模型名}_{mode}_{时间戳}.json`

```json
{
  "predictions": [0, 1, 2, ...],
  "probabilities": [[0.9, 0.05, 0.03, 0.02], ...],
  "num_samples": 100,
  "num_classes": 4,
  "dataset": "chaosu",
  "data_source": "内置数据集 (test): ./data/chaosu",
  "mode": "test",
  "timestamp": "2026-03-06T10:30:00",
  "model_name": "TSLANet",
  "checkpoint": "experiments_logs/.../ckp_best.pt",
  "batch_size": 128,
  "true_labels": [0, 1, 2, ...],
  "accuracy": 0.95,
  "confusion_matrix": [[25, 1, 0, 0], ...],
  "diagnosis": {
    "0": {
      "预测标签": 0,
      "置信度": 0.95,
      "故障原因": "正常运行",
      "处理方案": "无需处理",
      "真实标签": 0,
      "预测正确": true
    }
  }
}
```

### 3.7 故障诊断功能

通过 `--mapping` 指定的 Excel 映射文件（如 `class_mapping.xlsx`），将预测标签映射为：
- 故障原因（中文描述）
- 处理方案（操作建议）

禁用方式：`--no-diagnosis` 或不提供映射文件。

### 3.8 使用示例

```bash
# 基本预测（内置测试集 + 故障诊断）
python predict.py \
    --checkpoint experiments_logs/Exp1/run1/supervised_seed_123/saved_models/ckp_best.pt \
    --config configs/config.yaml \
    --mapping configs/class_mapping.xlsx \
    --show_samples 10 --show_diagnosis

# 外部数据预测
python predict.py \
    --checkpoint experiments_logs/.../ckp_best.pt \
    --config configs/config.yaml \
    --data_file new_data.pt \
    --output results/prediction_output.json

# 传统ML模型预测
python predict.py \
    --checkpoint experiments_logs/Exp4/LogisticRegression/supervised_seed_123/saved_models/ckp_last.pt \
    --config configs/config.yaml \
    --model RandomForest --device cpu

# 禁用诊断，仅输出预测
python predict.py \
    --checkpoint experiments_logs/.../ckp_best.pt \
    --config configs/config.yaml \
    --no-diagnosis

# 验证集预测
python predict.py \
    --checkpoint experiments_logs/.../ckp_best.pt \
    --config configs/config.yaml \
    --mode val --batch_size 64
```

| SVM | `C`, `kernel`, `gamma`, `random_state` |
| XGBoost | `n_estimators`, `max_depth`, `learning_rate`, `subsample` |
| LightGBM | `n_estimators`, `max_depth`, `learning_rate`, `num_leaves` |
| KNN | `n_neighbors`, `weights`, `algorithm`, `metric` |


## 5. 典型工作流

```bash
# 步骤1: 数据预处理
python preprocess_3D.py --config configs/preprocess.yaml

    --model TSLANet --training_mode supervised --num_epochs 100

    --mapping configs/class_mapping.xlsx \

```

```bash
# 步骤1: 自监督预训练
python train.py --config configs/config.yaml \
    --model TS-TCC --training_mode self_supervised --num_epochs 50

# 步骤2: 微调
python train.py --config configs/config.yaml \
    --model TS-TCC --training_mode fine_tune --num_epochs 100

# 步骤3: 预测
python predict.py \
    --checkpoint experiments_logs/Exp1/run1/fine_tune_seed_123/saved_models/ckp_best.pt \
    --config configs/config.yaml
```

### 5.3 多模型对比


## 6. 错误处理

| 错误场景 | 表现 | 解决方案 |
|----------|------|----------|
| 配置文件不存在 | `❌ 错误: 配置文件不存在` | 检查 `--config` 路径 |
| 检查点文件不存在 | `❌ 错误: 检查点文件不存在` | 检查 `--checkpoint` 路径 |
| 模型权重不匹配 | `❌ 加载模型权重失败` | 确保 checkpoint 与 `--model` 一致 |
| CUDA 不可用 | `⚠ CUDA 不可用，使用 CPU` | 自动降级到 CPU |
| 数据文件缺少 samples 字段 | `错误: 数据文件必须包含 'samples' 字段` | 检查 `.pt` 文件格式 |
