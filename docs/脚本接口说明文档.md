## 1. preprocess_3D.py — 3D数据预处理脚本

### 1.1 功能概述

将原始 CSV Tracelog 数据转换为 PyTorch 张量格式（`.pt`），完成特征提取、数据划分和标准化，生成可直接用于深度学习模型训练的 `train.pt`、`val.pt`、`test.pt` 文件。输出为3D张量 `[N, C, L]`。

### 1.2 命令行接口

```bash
python preprocess_3D.py --config <配置文件路径> [--override key1=value1 key2=value2 ...]
```

### 1.3 参数说明

| 参数 | 类型 | 必需 | 默认值 | 说明 |
|------|------|------|--------|------|
| `--config` | str | ✅ | — | 预处理配置文件路径（YAML格式） |
| `--override` | str[] | ❌ | — | 覆盖配置参数，格式 `key=value`，支持嵌套键如 `split.test_size=0.3` |

### 1.4 配置文件对照（configs/preprocess.yaml）

```yaml
paths:
  label_file: "标签文件路径(.csv)"        # 包含样本路径和标签的索引文件
  config_file: "传感器配置表路径(.csv)"    # tracelog标签点配置表
  output_dir: "输出目录"                  # 生成的.pt文件保存位置

features:
  target_tags:                            # 需要提取的传感器通道列表
    - grRotorSpeedFormSpeedRelay1
    - grRotorSpeedFormSpeedRelay2
    - grRotorSpeedFromCounterModule1
    - rotor_speed

processing:
  max_seq_len: 12000                      # 统一时间步长度
  missing_value_method: "interpolate"     # 空值处理: interpolate/ffill/bfill/mean/zero
  padding_mode: "constant"                # 填充模式: constant/edge/reflect

normalization:
  method: "zscore"                        # 标准化: zscore/minmax/robust/none
  save_stats: true                        # 是否保存标准化统计量
  stats_filename: "normalization_stats.npz"

split:
  test_size: 0.4                          # 测试+验证集占比
  val_test_split: 0.5                     # 验证集在(测试+验证)中的占比
  random_state: 42                        # 随机种子
  stratify: true                          # 是否分层抽样

output:
  train_file: "train.pt"
  val_file: "val.pt"
  test_file: "test.pt"
```

### 1.5 执行流程

```
加载配置 → DataPreprocessor.process() → split_and_normalize() → save_datasets()
```

1. 读取 YAML 配置，应用 `--override` 覆盖
2. `DataPreprocessor(config)` 初始化预处理器
3. `process()` — 读取原始 CSV，提取特征，返回 `(X, y)`
4. `split_and_normalize(X, y)` — 按配置比例划分数据集并标准化
5. `save_datasets(data_splits)` — 保存为 `.pt` 文件

### 1.6 输出文件格式

每个 `.pt` 文件包含：
```python
{
    'samples': Tensor[N, C, L],  # N=样本数, C=通道数, L=时间步
    'labels':  Tensor[N]         # 整数标签
}
```

### 1.7 错误编码

| 错误码 | 名称 | 说明 |
|--------|------|------|
| 1001 | CONFIG_LOAD_ERROR | 配置文件加载失败，路径不存在或格式错误 |
| 1002 | CONFIG_OVERRIDE_ERROR | 覆盖参数格式不正确，无法解析 key=value |
| 1003 | PREPROCESS_INIT_ERROR | DataPreprocessor 初始化失败，配置缺失 |
| 1004 | PROCESS_ERROR | 预处理过程中发生错误（读取/转换/检查数据） |
| 1005 | SPLIT_NORMALIZE_ERROR | 划分或标准化数据时出错 |
| 1006 | SAVE_DATASET_ERROR | 保存数据集到磁盘失败（路径或权限问题） |
| 1999 | UNKNOWN_ERROR | 未知错误 |

### 1.8 使用示例

```bash
# 基本用法
python preprocess_3D.py --config configs/preprocess.yaml

# 覆盖参数
python preprocess_3D.py --config configs/preprocess.yaml \
    --override split.test_size=0.3 normalization.method=minmax

# 修改输出目录
python preprocess_3D.py --config configs/preprocess.yaml \
    --override paths.output_dir=./data/my_dataset
```

## 2. preprocess_2D.py — 2D数据预处理脚本

### 2.1 功能概述

从 Excel 索引文件读取原始 Tracelog 数据路径，通过 `FaultDiagnosisPipeline` 批量提取2D特征向量，进行数据清洗和标签编码，按 8:1:1 比例生成训练集、验证集和测试集，保存为 `.pt` 格式文件。适用于传统机器学习模型（RandomForest、SVM、XGBoost 等）的训练数据准备。

### 2.2 命令行接口

```bash
python preprocess_2D.py
```

> 无命令行参数，所有配置通过 `configs/preprocess_2D.yaml` 和 `configs/config_loader.py` 导入。

### 2.3 核心函数

| 函数名 | 说明 |
|--------|------|
| `Process_Data()` | 数据预处理主流程入口，无入参，无返回值 |

### 2.4 配置依赖（configs/preprocess_2D.yaml）

通过 `configs/config_loader.py` 自动加载以下关键配置：

| 配置项 | 来源路径 | 说明 |
|--------|----------|------|
| `DATA_SOURCE_EXCEL` | `data.source_excel` | 数据索引 Excel 文件路径 |
| `PROCESSED_DATA_DIR` | `data.processed_dir` | 处理后数据输出目录 |
| `COL_TRACELOG_PATH` | `excel.trace_path_column` | Excel 中 Tracelog 路径列名 |
| `COL_LABEL` | `excel.label_column` | Excel 中标签列名 |
| `RANDOM_SEED` | `data_split.random_seed` | 随机种子（默认42） |

### 2.5 执行流程

```
读取Excel索引 → 划分索引(8:1:1) → FaultDiagnosisPipeline批量提取特征 → 保存.pt文件
```

1. 从 `DATA_SOURCE_EXCEL` 读取 Excel，获取 Tracelog 路径和标签
2. 使用 `train_test_split` 按 8:1:1 比例划分索引
3. 对每个分片调用 `FaultDiagnosisPipeline.process_batch_to_pt()` 提取特征
4. 保存为 `train.pt`、`val.pt`、`test.pt`

### 2.6 输出文件格式

每个 `.pt` 文件包含：
```python
{
    'samples': Tensor[N, F],  # N=样本数, F=特征维度（2D特征向量）
    'labels':  Tensor[N]      # 整数标签
}
```

### 2.7 使用示例

```bash
# 直接运行（配置通过 configs/preprocess_2D.yaml 自动加载）
python preprocess_2D.py
```

> 运行前请确保 `configs/preprocess_2D.yaml` 中的 `data.source_excel` 路径正确指向数据索引 Excel 文件。

## 3. prepare_dp_data.py — 深度学习预测数据准备脚本

### 3.1 功能概述

从单个 Tracelog CSV 文件生成用于深度学习模型预测的 `.pt` 文件。使用与训练数据预处理相同的逻辑（特征提取、缺失值处理、序列长度调整、标准化），确保预测数据与训练数据格式一致。输出为3D张量 `[1, C, L]`。

### 3.2 命令行接口

```bash
python prepare_dp_data.py --tracelog <CSV文件路径> --config <配置文件路径> [可选参数]
```

### 3.3 参数说明

| 参数 | 类型 | 必需 | 默认值 | 说明 |
|------|------|------|--------|------|
| `--tracelog` | str | ✅ | — | Tracelog CSV 文件路径 |
| `--config` | str | ✅ | — | 预处理配置文件路径（与训练时使用的配置相同） |
| `--output` | str | ❌ | `./external_data/predict_data.pt` | 输出 `.pt` 文件路径 |
| `--include-label` | flag | ❌ | `false` | 是否包含虚拟标签（某些预测脚本可能需要） |

### 3.4 配置文件对照（configs/preprocess.yaml）

复用与 `preprocess_3D.py` 相同的配置文件，关键配置项：

| 配置路径 | 说明 |
|----------|------|
| `features.target_tags` | 需要提取的传感器通道列表 |
| `processing.max_seq_len` | 统一时间步长度 |
| `processing.missing_value_method` | 空值处理方法 |
| `processing.padding_mode` | 填充模式 |
| `normalization.method` | 标准化方法 |
| `normalization.save_stats` | 是否使用训练时保存的标准化统计量 |
| `paths.config_file` | 传感器同义词配置表路径 |
| `paths.output_dir` | 标准化统计量文件所在目录 |

### 3.5 执行流程

```
加载配置 → 加载标准化统计量 → 读取CSV → 匹配列名 → 缺失值处理 → 调整序列长度 → 标准化 → 保存.pt
```

1. 加载 YAML 配置和训练时保存的标准化统计量（`normalization_stats.npz`）
2. 读取 Tracelog CSV，通过同义词组匹配目标列
3. 处理缺失值和无穷值
4. 调整序列长度（填充或截断至 `max_seq_len`）
5. 使用训练时的统计量进行标准化
6. 保存为 `.pt` 文件

### 3.6 输出文件格式

```python
{
    'samples': Tensor[1, C, L],           # 1个样本, C=通道数, L=时间步
    'labels':  Tensor[1]                  # 可选，虚拟标签（仅当 --include-label 时）
}
```

### 3.7 错误编码

| 错误码 | 名称 | 说明 |
|--------|------|------|
| 4101 | CONFIG_LOAD_ERROR | 配置文件加载失败 |
| 4102 | TRACELOG_NOT_FOUND | Tracelog 文件不存在 |
| 4103 | PROCESS_ERROR | Tracelog 处理过程出错 |
| 4104 | SAVE_ERROR | 保存 .pt 文件失败 |
| 4199 | UNKNOWN_ERROR | 未知错误 |

### 3.8 使用示例

```bash
# 基本用法
python prepare_dp_data.py \
    --tracelog data_preprocessing/Tracelog/24-01-10-07_49_13_830_01010_SafetyRotorOv.csv \
    --config configs/preprocess.yaml

# 指定输出路径
python prepare_dp_data.py \
    --tracelog path/to/tracelog.csv \
    --config configs/preprocess.yaml \
    --output ./external_data/my_predict_data.pt

# 包含虚拟标签
python prepare_dp_data.py \
    --tracelog path/to/tracelog.csv \
    --config configs/preprocess.yaml \
    --include-label

# 生成后可直接用于预测
python predict.py --data_file ./external_data/predict_data.pt \
    --checkpoint experiments_logs/.../ckp_best.pt \
    --config configs/config.yaml
```

## 4. prepare_ml_data.py — 机器学习预测数据准备脚本

### 4.1 功能概述

从 Excel 索引或目录批量加载 Tracelog 数据，通过 `FaultDiagnosisPipeline` 提取2D特征向量，保存为 `.pt` 文件，供传统机器学习模型（RandomForest、SVM 等）进行批量预测。同时支持加载已训练的 ML 模型直接执行预测并生成结果报告。

### 4.2 命令行接口

```bash
python prepare_ml_data.py
```

> 无命令行参数，所有配置通过 `configs/preprocess_2D.yaml` 和 `configs/config_loader.py` 导入。

### 4.3 核心类与函数

| 类/函数 | 说明 |
|---------|------|
| `TestDataLoader` | 测试数据加载器，从 Excel 或目录读取 Tracelog 路径并加载原始数据 |
| `TestDataLoader.load_test_paths()` | 读取 Excel 获取文件路径列表，支持目录扫描模式 |
| `TestDataLoader.load_batch()` | 逐个读取并返回 `(filename, dataframe)` 列表 |
| `ModelTester` | 模型预测器，加载 `.pt` 模型文件并执行预测 |
| `ModelTester.load_artifacts()` | 加载模型、scaler、label_encoder |
| `ModelTester.predict(X, filenames)` | 执行预测，返回包含预测结果和置信度的 DataFrame |
| `ModelTester.visualize(df_results)` | 生成预测分布和置信度分布可视化图 |
| `run_pipeline_inference(batch_data, save_pt_path)` | 使用 Pipeline 批量提取特征，可选保存为 `.pt` |
| `main()` | 主流程入口 |

### 4.4 配置依赖（configs/preprocess_2D.yaml）

| 配置项 | 来源路径 | 说明 |
|--------|----------|------|
| `DATA_SOURCE_TEST_EXCEL` | `data.source_test_excel` | 测试数据索引 Excel 或目录路径 |
| `MODEL_SAVE_DIR` | `model.save_dir` | 模型保存目录 |
| `MODEL_FILENAME` | `model.filename` | 模型文件名 |
| `PREDICTION_RESULT_CSV` | `output.prediction_csv` | 预测结果 CSV 输出路径 |
| `PREDICTION_REPORT_IMG` | `output.prediction_report_img` | 预测报告图片输出路径 |
| `DEFAULT_FAULT_TIME` | `constants.default_fault_time` | 默认故障时间点 |
| `TIMESTAMP_WINDOW` | `constants.timestamp_window` | 故障截取时间窗口 |
| `COL_TRACELOG_PATH` | `excel.trace_path_column` | Excel 中 Tracelog 路径列名 |

### 4.5 执行流程

```
加载数据源(Excel/目录) → 逐个读取CSV → Pipeline提取特征 → 保存.pt文件
```

1. 从 `DATA_SOURCE_TEST_EXCEL` 读取 Excel 或扫描目录获取 CSV 路径
2. `DataProcessor.extract_columns_with_fallback()` 逐个读取原始传感器数据
3. `FaultDiagnosisPipeline.run()` 提取每个样本的特征向量
4. 合并特征矩阵，保存为 `.pt` 文件和文件名映射 CSV

### 4.6 输出文件

| 文件 | 说明 |
|------|------|
| `prediction_features.pt` | 特征张量文件，包含 `{'samples': Tensor[N, F]}` |
| `prediction_features_filenames.csv` | 文件名映射表，用于追溯样本来源 |

### 4.7 使用示例

```bash
# 直接运行（配置通过 configs/preprocess_2D.yaml 自动加载）
python prepare_ml_data.py
```

> 运行前请确保：
> - `configs/preprocess_2D.yaml` 中的 `data.source_test_excel` 路径正确
> - 模型文件存在于 `model.save_dir` / `model.filename` 指定的位置

## 5. train.py — 统一训练脚本

### 5.1 功能概述

统一的模型训练入口，支持深度学习模型（TSLANet、TS-TCC、base_CNN）、储层计算模型（RC）和传统机器学习模型（RandomForest、SVM、XGBoost、LightGBM、KNN、LogisticRegression）。通过配置文件切换模型，命令行参数可覆盖配置。

### 5.2 命令行接口

```bash
python train.py --config <配置文件路径> [可选参数]
```

### 5.3 参数说明

| 参数 | 类型 | 必需 | 默认值 | 说明 |
|------|------|------|--------|------|
| `--config` | str | ❌ | `config.yaml` | YAML 配置文件路径 |
| `--model` | str | ❌ | 配置文件值 | 模型名称，覆盖 `experiment.model` |
| `--dataset` | str | ❌ | 配置文件值 | 数据集名称，覆盖 `dataset.selected` |
| `--training_mode` | str | ❌ | 配置文件值 | 训练模式，覆盖 `training.mode` |
| `--device` | str | ❌ | 配置文件值 | 运行设备 `cuda`/`cpu`，覆盖 `device` |
| `--seed` | int | ❌ | 配置文件值 | 随机种子，覆盖 `experiment.seed` |
| `--batch_size` | int | ❌ | 配置文件值 | 批次大小，覆盖 `training.batch_size` |
| `--num_epochs` | int | ❌ | 配置文件值 | 训练轮数，覆盖 `training.num_epochs` |

> 参数优先级：命令行 > 配置文件 > 内置默认值

### 5.4 支持的模型与训练器映射

| 模型名称 | 类别 | 训练器 | 输入维度 | 设备 |
|----------|------|--------|----------|------|
| TSLANet | 深度学习 | UnifiedTrainer | 3D `[N,C,L]` | GPU/CPU |
| TS-TCC | 深度学习 | UnifiedTrainer | 3D `[N,C,L]` | GPU/CPU |
| base_CNN | 深度学习 | UnifiedTrainer | 3D `[N,C,L]` | GPU/CPU |
| RC | 储层计算 | RCTrainer | 3D `[N,C,L]` | GPU/CPU |
| RandomForest | 传统ML | MLTrainer | 2D `[N,F]`（自动展平） | CPU |
| SVM | 传统ML | MLTrainer | 2D `[N,F]` | CPU |
| XGBoost | 传统ML | MLTrainer | 2D `[N,F]` | CPU |
| LightGBM | 传统ML | MLTrainer | 2D `[N,F]` | CPU |
| KNN | 传统ML | MLTrainer | 2D `[N,F]` | CPU |
| LogisticRegression | 传统ML | MLTrainer | 2D `[N,F]` | CPU |

### 5.5 训练模式

| 模式 | 配置值 | 说明 |
|------|--------|------|
| 监督学习 | `supervised` | 标准有标签训练 |
| 自监督预训练 | `self_supervised` | 无标签对比学习预训练（TS-TCC/TSLANet） |
| 微调 | `fine_tune` | 加载预训练权重后全参数微调 |
| 线性评估 | `train_linear` | 冻结主干网络，仅训练分类头 |
| 随机初始化 | `random_init` | 随机初始化后冻结部分层训练 |

### 5.6 配置文件对照（configs/config.yaml）

```yaml
experiment:
  description: 'Exp1'          # 实验名称 → 日志子目录
  run_description: 'run1'      # 运行名称 → 日志子目录
  seed: 123                    # 随机种子
  model: 'TSLANet'             # 模型选择

training:
  mode: 'supervised'           # 训练模式
  num_epochs: 100              # 训练轮数
  batch_size: 16               # 批次大小
  learning_rate: 0.001         # 学习率
  weight_decay: 0.0003         # 权重衰减
  beta1: 0.9                   # Adam β1
  beta2: 0.99                  # Adam β2

pretraining:
  load_pretrained: false       # 是否加载预训练
  pretrained_path: null        # 预训练模型路径
  delete_layers: ['logits']    # 加载时删除的层
  freeze_backbone: false       # 是否冻结主干

dataset:
  selected: 'chaosu'           # 数据集名称
  data_path: './data'          # 数据根目录

# 模型特定配置（按模型名称索引）
TSLANet:
  emb_dim: 128
  depth: 2
  patch_size: 8
  dropout_rate: 0.15
  ...

# 数据集特定配置（按数据集名称索引）
dataset_configs:
  chaosu:
    input_channels: 4
    seq_len: 12000
    num_classes: 4
    num_channels: 4
```

### 5.7 执行流程

```
加载配置 → 设置随机种子 → 加载数据 → 创建模型 → [加载预训练] → 创建优化器 → 选择训练器 → 训练 → 测试评估 → 保存
```

### 5.8 输出目录结构

```
experiments_logs/
└── {experiment.description}/
    └── {experiment.run_description}/
        └── {training_mode}_seed_{seed}/
            ├── logs_YYYYMMDD_HHMMSS.log       # 训练日志
            ├── config.yaml                     # 配置快照
            ├── metrics.csv                     # 训练指标（如有）
            ├── classification_report.xlsx      # 分类报告（监督模式）
            ├── confusion_matrix.png            # 混淆矩阵图（监督模式）
            └── saved_models/
                ├── ckp_best.pt                 # 最佳模型检查点
                └── ckp_last.pt                 # 最后一轮检查点
```

### 5.9 错误编码

| 错误码 | 名称 | 说明 |
|--------|------|------|
| 2101 | CONFIG_LOAD_ERROR | 加载YAML配置失败 |
| 2102 | DATA_LOADER_ERROR | 数据加载或生成dataloader失败 |
| 2103 | MODEL_CREATION_ERROR | 模型或配置获取失败 |
| 2104 | PRETRAIN_LOAD_ERROR | 预训练模型加载失败 |
| 2105 | TRAINING_ERROR | 训练过程出错 |
| 2106 | EVALUATION_ERROR | 测试/评估出错 |
| 2107 | CONFIG_SAVE_ERROR | 保存配置到磁盘失败 |
| 2999 | UNKNOWN_ERROR | 未知错误 |

### 5.10 使用示例

```bash
# 基本训练（使用配置文件默认值）
python train.py --config configs/config.yaml

# 指定模型和训练模式

    --model TSLANet --training_mode supervised --num_epochs 50
```

## 6. predict.py — 统一预测脚本

### 6.1 功能概述

统一的模型推理入口，支持所有已训练模型的预测。集成故障诊断映射功能，可输出故障原因和处理方案。支持内置数据集和外部数据文件两种输入方式。

### 6.2 命令行接口

```bash
python predict.py --checkpoint <检查点路径> --config <配置文件路径> [可选参数]
```

### 6.3 参数说明

| 参数 | 类型 | 必需 | 默认值 | 说明 |
|------|------|------|--------|------|
| `--checkpoint` | str | ✅ | — | 模型检查点路径（`.pt` 文件） |
| `--config` | str | ✅ | — | 配置文件路径（`.yaml` 文件） |
| `--model` | str | ❌ | 从checkpoint读取 | 模型名称（覆盖checkpoint中的记录） |
| `--mapping` | str | ❌ | `class_mapping.xlsx` | 故障诊断映射 Excel 文件路径 |
| `--no-diagnosis` | flag | ❌ | `false` | 禁用故障诊断功能 |
| `--data_file` | str | ❌ | — | 外部数据文件路径（`.pt`），与 `--dataset` 二选一 |
| `--dataset` | str | ❌ | `chaosu` | 数据集名称（使用内置数据集时） |
| `--data_path` | str | ❌ | `./data` | 数据根目录（使用内置数据集时） |
| `--mode` | str | ❌ | `test` | 预测数据集分片：`train`/`val`/`test` |
| `--device` | str | ❌ | `cuda` | 运行设备：`cuda`/`cpu` |
| `--output` | str | ❌ | 自动生成 | 输出 JSON 文件路径 |
| `--batch_size` | int | ❌ | `128` | 批处理大小 |
| `--show_samples` | int | ❌ | `5` | 控制台显示前 N 个样本的预测详情 |
| `--show_diagnosis` | flag | ❌ | `false` | 为每个样本显示详细故障诊断信息 |

### 6.4 数据输入方式

#### 方式一：内置数据集（默认）

从 `{data_path}/{dataset}/` 目录加载预处理好的 `.pt` 文件，通过 `--mode` 选择 train/val/test 分片。

```bash
python predict.py \
    --checkpoint experiments_logs/Exp1/run1/supervised_seed_123/saved_models/ckp_best.pt \
    --config configs/config.yaml \
    --dataset chaosu --mode test
```

#### 方式二：外部数据文件

加载任意 `.pt` 文件，文件格式要求：

```python
# 带标签（可计算准确率）
{'samples': Tensor[N, C, L], 'labels': Tensor[N]}

# 无标签（纯预测模式）
{'samples': Tensor[N, C, L]}
```

```bash
python predict.py \
    --checkpoint experiments_logs/.../ckp_best.pt \
    --config configs/config.yaml \
    --data_file external_data/new_samples.pt
```

### 6.5 模型预测策略

| 模型类别 | 预测方式 | 设备 | 数据处理 |
|----------|----------|------|----------|
| 深度学习（TSLANet, TS-TCC, base_CNN） | 迭代预测（逐批次） | GPU/CPU | 3D 输入 `[N,C,L]` |
| RC | 批量预测（一次性） | GPU/CPU | 3D 输入 `[N,C,L]` |
| 传统ML（RandomForest, SVM 等） | 批量预测（一次性） | CPU | 自动展平为 2D `[N,F]` |

## 9. 错误处理

### 9.1 脚本错误编码汇总

| 脚本 | 错误码范围 | 说明 |
|------|-----------|------|
| `preprocess_3D.py` | 1001–1999 | 数据预处理相关错误 |
| `train.py` | 2101–2999 | 模型训练相关错误 |
| `predict.py` | 3101–3999 | 模型预测相关错误 |
| `prepare_dp_data.py` | 4101–4199 | 深度学习预测数据准备错误 |

### 9.2 常见问题排查

| 错误场景 | 表现 | 解决方案 |
|----------|------|----------|
| 配置文件不存在 | 错误码 1001/2101/4101 | 检查 `--config` 路径是否正确 |
| 检查点文件不存在 | 错误码 3101 | 检查 `--checkpoint` 路径 |
| 模型权重不匹配 | 错误码 3106 | 确保 checkpoint 与 `--model` 一致 |
| CUDA 不可用 | `⚠ CUDA 不可用，使用 CPU` | 自动降级到 CPU，无需处理 |
| 数据文件缺少 samples 字段 | 错误码 3104 | 检查 `.pt` 文件格式 |
| 映射文件不存在 | `⚠ 故障诊断映射文件不存在` | 检查 `--mapping` 路径或使用 `--no-diagnosis` |
| 传统ML模型未训练 | `❌ 模型未训练，无法进行预测` | 确保 checkpoint 包含已训练的模型 |
| Excel 列名不匹配 | 数据加载失败 | 检查 `preprocess_2D.yaml` 中的 `column_mapping` 和 `excel` 配置 |
| Tracelog 文件不存在 | 错误码 4102 | 检查 `--tracelog` 路径 |
| 标准化统计量缺失 | `⚠ 未找到标准化统计量文件` | 先运行 `preprocess_3D.py` 生成统计量 |
